- Rewritten old posts keep their slug and pubDate and add `updatedDate`

## Gotchas
- git-guard rejects commit messages containing "claude code" (it reads that as AI attribution). Word messages around it
- CPPChess bugs: (1) magic-bitboard truncation (verified 2026-10-19 with a brute-force test in the scratchpad): src/attack_mask.cpp stores the 64-bit magic in `const int magic_bitboard` and the index in `int magic_index` while building the tables, but the lookup uses the full 64-bit magic, so about 88% of random rook and bishop lookups return the wrong mask. Making both `uint64_t` gives 0 wrong out of 12,800. The rook case also falls through into `case King` (harmless, because it ORs the same mask). (2) src/movegen.cpp checks white promotions on rank 8 (a8..h8) instead of rank 7, in both the push and capture branches, and a missing `else` adds a plain push after the 4 promotions. Neither fix is pushed to CPPChess
- Screenshots: `npx astro preview --port 4329` plus headless Chrome (`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --screenshot=... --window-size=...`, and `--force-dark-mode` for dark). Headless windows can't go narrower than about 500px, so test mobile by loading the site in 390px iframes inside a local HTML file
- In zsh, `bd35051^` inside a variable misbehaves; use `bd35051~1` with `git cat-file blob` to extract binary files.

## Gotchas (deploy)
- Astro strips a line break that sits right next to a tag, so `text\n<a>` renders as `text<a>` with no space. Keep the break between plain words (`on\nmy <a>`). Scan with: grep -rhoE '[A-Za-z,.]<a href|</a>[A-Za-z(]' dist --include=*.html
- Blog posts come from `getPosts()` in src/posts.ts (filters drafts in production, sorts newest first); don't call getCollection('blog') directly
- New internal links must use `withBase()`, or they 404 on the live site. Check with `npm run build && npx astro preview` (serves under /portfolio/)
- v2 now has its own .github/workflows (deploy.yml replaces main's Eleventy one; sync-resume.yml ported with the public/ path and an explicit contents/actions write permission)
- The resume PDF belongs in `public/`, not `src/assets/documents/` (the old sync path)
